Pengaturan Sistem & Integrasi

Memuat status integrasi...

Integrasi ini memungkinkan Evan-ID untuk melakukan sinkronisasi serta memvalidasi data pegawai dengan API pusat data kepegawaian (BEGAWI-ASN).

Alamat server aplikasi bank-data-pegawai yang aktif.

API Key yang didapatkan dari menu Integrasi di dashboard bank-data-pegawai.

Keterangan Integrasi:

Jika status integrasi **Aktif**, sistem akan secara dinamis mengambil daftar jabatan dan data nominatif ASN langsung dari database bank-data-pegawai (BEGAWI-ASN) yang berjalan di port 3001. Perubahan data di aplikasi bank data pegawai akan otomatis tercermin di sini secara real-time.
